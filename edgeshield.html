Offscreen Document Pattern

EdgeShield runs in a separate offscreen document—an isolated browsing context that:

  • Operates independently of visible UI
  • Has separate JavaScript event loop
  • Communicates via message passing
  • Terminated when not in use

WebAssembly Execution

Models compile to WASM bytecode for near-native performance:

  • SIMD instructions for vector operations
  • SharedArrayBuffer for multi-threading
  • 128-bit memory sandbox
  • Streaming compilation

Local Vector Database

SQLite compiled to WASM with FAISS for similarity search:

  • Embeddings stored locally
  • FAISS index for fast retrieval
  • Encrypted at rest

EdgeShield Initialization

TypeScript 
// Initialize EdgeShield WASM runtime
const edgeShield = await EdgeShield.initialize({
  runtime: 'onnx', // 'onnx' | 'webllm'
  models: [
    'legality-classifier',
    'tone-analyzer',
    'factuality-check'
  ],
  memoryLimit: '128mb',
  enableSIMD: true,
  cacheModels: true
});

// Run local inference
const result = await edgeShield.infer({
  content: textToAnalyze,
  classifiers: ['legality', 'tone'],
  timeout: 5000
});

Security Model

Defense in depth: multiple layers of protection ensure content never escapes the device.

Content Security Policy

Strict CSP headers prevent external resource loading:

default-src 'none';
script-src 'self' 'wasm-unsafe-eval';
connect-src 'none';
img-src 'none';
style-src 'none';

'wasm-unsafe-eval' required for WebAssembly compilation

Memory Isolation

WASM memory sandbox prevents access to host system:

  • Linear memory capped at 128MB
  • No direct DOM access from WASM
  • Explicit memory management
  • Automatic cleanup on termination

Model Encryption

Downloaded models encrypted at rest:

  • AES-256-GCM encryption
  • PBKDF2 key derivation (100k iterations)
  • Hardware-backed where available

Network Isolation

Zero network connectivity during inference:

  • No fetch/XHR from WASM context
  • WebSocket disabled
  • WebRTC disabled
  • Service Worker offline-first
