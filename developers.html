Quickstart Guide

Get up and running with the Fenton Platform API in under 5 minutes. This guide covers authentication, your first request, and basic integration patterns.

1

Get API Key

Sign up for a developer account and generate your API key from the dashboard.

2

Install SDK

Add the Fenton SDK to your project via npm, pip, or your preferred package manager.

3

Make Request

Call the API with your authentication token and start building with Fenton Platform.

Installation

npm
npm install @fenton/platform-sdk
pip
pip install fenton-platform
CDN
<script src="https://cdn.fenton.ai/platform/v2/fenton.min.js"></script>

Authentication

The Fenton Platform API uses API keys for authentication. Include your key in the Authorization header of all requests.

Security Notice

Never expose your API key in client-side code. Use environment variables and server-side requests for production applications.

Authorization Header
Authorization: Bearer fenton_live_<your_api_key>

Initializing the SDK

JavaScript 
import { FentonClient } from '@fenton/platform-sdk';

const client = new FentonClient({
  apiKey: process.env.FENTON_API_KEY,
  environment: 'production' // or 'sandbox'
});

SecureBridge API

Zero-trust hybrid encryption protocol for secure data transmission across distributed AI providers.

POST /v2/securebridge/session
Create encrypted session

Initialize a new SecureBridge session with hybrid X25519 + AES-256-GCM encryption.

// Request
const session = await client.secureBridge.createSession({
  providers: ['openai', 'anthropic'],
  encryption: 'hybrid',
  keyRotation: '15m'
});

// Response
{
  "sessionId": "sb_live_abc123",
  "publicKey": "-----BEGIN PUBLIC KEY-----\\n...",
  "expiresAt": "2025-01-15T10:30:00Z"
}
POST /v2/securebridge/encrypt
Encrypt payload

Encrypt data for transmission to AI providers.

const encrypted = await client.secureBridge.encrypt({
  sessionId: 'sb_live_abc123',
  payload: { prompt: 'Analyze this content...' },
  provider: 'openai'
});

ContextVault API

Persistent memory architecture with 90% token cost reduction through intelligent context compression.

POST /v2/vault/store
Store compressed context 
const stored = await client.contextVault.store({
  vaultId: 'user_123_conversations',
  data: {
    messages: ['...', '...'],
    metadata: { topic: 'support' }
  },
  compression: 'semantic', // 'semantic' | 'lossless'
  ttl: '30d'
});

// Returns compressed token count and savings
{
  "storedId": "cv_abc123",
  "originalTokens": 5000,
  "compressedTokens": 500,
  "savingsPercent": 90
}
GET /v2/vault/retrieve/:vaultId
Retrieve context 
const context = await client.contextVault.retrieve({
  vaultId: 'user_123_conversations',
  format: 'expanded' // Reconstitutes compressed data
});

AROL Engine API

Adaptive Response & Optimisation Layer for intelligent multi-provider AI orchestration.

POST /v2/arol/orchestrate
Multi-provider orchestration 
const result = await client.arol.orchestrate({
  strategy: 'consensus', // 'consensus' | 'fastest' | 'weighted'
  providers: ['openai', 'anthropic', 'venice'],
  prompt: 'Analyze the sentiment of...',
  consensusThreshold: 0.75,
  timeout: 5000
});

// Returns consensus result with confidence scores
{
  "consensus": "positive",
  "confidence": 0.89,
  "providerResponses": [...],
  "dissentDetected": false
}
POST /v2/arol/analyze-dissent
Contradiction detection 
const analysis = await client.arol.analyzeDissent({
  responses: ['Claim A', 'Claim B'],
  context: 'political-debate'
});

// Returns contradiction analysis
{
  "contradictionDetected": true,
  "contradictionScore": 0.82,
  "explanation": "Statements contradict on timeline..."
}

LLM DLP Core API

Data loss prevention for large language models. PII detection, content classification, and policy enforcement.

POST /v2/dlp/scan
Scan for sensitive data 
const scan = await client.llmDlp.scan({
  content: 'Contact john.doe@email.com or call 555-0123...',
  rules: [
    'pii',           // Personal Identifiable Information
    'credentials',   // API keys, passwords
    'financial',   // Credit cards, bank accounts
    'gdpr'         // GDPR protected categories
  ],
  redact: true
});

// Returns scan results with redacted content
{
  "violationsFound": 2,
  "redactedContent": "Contact [EMAIL_REDACTED] or call [PHONE_REDACTED]...",
  "violations": [
    { "type": "email", "position": [8, 25] },
    { "type": "phone", "position": [35, 44] }
  ]
}
PUT /v2/dlp/policy
Configure policy 
await client.llmDlp.setPolicy({
  policyId: 'enterprise-default',
  rules: {
    blockUnverifiedDomains: true,
    allowedDomains: ['company.com', 'trusted-partner.com'],
    requireConsent: true,
    auditLog: true
  }
});
